LocalVault v1.0.0

A zero-network, local-only password manager built with Electron.

  • Zero Network: Strictly offline. No sockets, no telemetry, external navigation denied.
  • Encryption: AES-256-GCM authenticated encryption with unique random IV per entry.
  • Key Derivation: scrypt (N=16384, r=8, p=1) with cryptographic 16-byte random salts.
  • Clipboard Safety: Cleared automatically after 45 seconds or immediately on lock.
  • Memory Hygiene: Passwords held in renderer only during active reveal timeout.
